# MO31_Leonov_Digits

Учебное приложение с полем для рисования цифр. Создано из шаблона `avalonia.app`: C#, .NET 10, Avalonia 12.1.2. В окне расположены 3 столбца и 5 строк кнопок, каждая размером 75 × 75 единиц Avalonia. На Retina это логический размер с учётом масштабирования экрана. Вначале все пиксели белые. Нажатие делает пиксель чёрным, повторное — белым. Под полем расположена кнопка «Распознать» без обработчика: пока она ничего не делает. Обучающие примеры сохраняются в train.txt, тестовые — в test.txt. Нейросеть пока не реализована.

## Открытие в Rider

1. В Rider выбери **Open** или **File → Open**.
2. Открой файл `MO31_Leonov_Digits.csproj` из этой папки.
3. Дождись загрузки проекта и восстановления пакетов NuGet.
4. Выбери конфигурацию запуска `MO31_Leonov_Digits` и нажми зелёный треугольник **Run**.

Rider поддерживает Avalonia XAML. Плагин AvaloniaRider нужен только при желании использовать предварительный просмотр разметки; для сборки и запуска он не обязателен.

Если Rider не найдёт .NET автоматически, в настройках **Build, Execution, Deployment → Toolset and Build** укажи путь к .NET CLI: `/usr/local/share/dotnet/dotnet`.

## Команды из папки проекта

```sh
dotnet build
dotnet run
```

На этом Mac проверено наличие .NET SDK 10.0.400 с архитектурой arm64 и Avalonia.Templates 12.1.2. Дополнительная установка SDK и шаблонов не требуется.

Проверка 9 сентября 2026 года: `dotnet build` завершилась успешно, 0 ошибок и 0 предупреждений. Графический запуск окна отдельно не проверялся.

## Основные файлы

- `FormMain.axaml` — разметка главного окна: какие элементы в нём находятся и как расположены. Начнём с этого файла.
- `FormMain.axaml.cs` — C#-код окна. `InitializeComponent()` загружает разметку. Общий обработчик `Pixel_Click` получает нажатую кнопку через `sender` и переключает её фон между белым и чёрным.
- `App.axaml` — общие стили приложения. Сейчас подключена стандартная тема Fluent.
- `App.axaml.cs` — загружает настройки приложения и создаёт главное окно.
- `Program.cs` — точка входа: запускает Avalonia и выбирает поддержку текущей операционной системы.
- `MO31_Leonov_Digits.csproj` — настройки проекта: версия .NET и зависимости Avalonia. `WinExe` означает оконное приложение и не мешает запуску на macOS.
- `app.manifest` — параметры совместимости для Windows из шаблона; на macOS не используется.
- `bin/` и `obj/` — автоматически созданные результаты сборки. Вручную их редактировать не нужно.

Используется обычный код окна, без MVVM. В проекте оставлены три прямые зависимости: Avalonia, Avalonia.Desktop и Avalonia.Themes.Fluent. Пакеты дополнительного шрифта и инструментов диагностики из шаблона удалены.

## Как устроено поле

В `FormMain.axaml` контейнер `UniformGrid` раскладывает 15 явно записанных кнопок в 5 строк и 3 столбца. Кнопки идут по порядку слева направо, сверху вниз.

Стиль `UniformGrid > Button` задаёт кнопкам-пикселям ширину и высоту 75. Всё поле имеет размер 225 × 375. `ControlTemplate` описывает пиксель как квадрат с заданным фоном и серой рамкой, не подменяя цвет пикселя стандартной подсветкой кнопки. Этот стиль не применяется к кнопке «Распознать».

У всех пикселей указано `Background="White"` и `Click="Pixel_Click"`. Первое задаёт начальный белый цвет, второе подключает общий обработчик нажатия. Рисуй цифру, нажимая на нужные пиксели; повторное нажатие стирает пиксель.

`StackPanel` располагает поле и кнопку «Распознать» друг под другом с промежутком 16. Кнопка имеет размер 225 × 40. У неё нет обработчика `Click`, поэтому нажатие пока ничего не запускает.

## Возможные следующие шаги

Массив `double[] inputPixels` из 15 чисел уже создан в конструкторе. При нажатии `Pixel_Click` меняет цвет и записывает значение в `inputPixels[button.TabIndex]`: чёрный — `1d`, белый — `0d`. Пиксели имеют индексы от 0 до 14. Кнопка «Распознать» не подключена к этому обработчику.

Под кнопкой «Распознать» добавлены поле `numericUpDown_NecessaryOutput` для правильной цифры от 0 до 9 и кнопки `ButtonSaveTrainSample` («Сохранить обучающую») и `ButtonSaveTestSample` («Сохранить тестовую»). Цифру можно вводить с клавиатуры или менять стрелками с шагом 1. Их `TabIndex` — 16, 17 и 18. К кнопкам сохранения подключены обработчики `ButtonSaveTrainSample_Click` и `ButtonSaveTestSample_Click` в `FormMain.axaml.cs`. Первый добавляет обучающий пример в `train.txt`, второй — тестовый пример в `test.txt`.

1. Добавить очистку: сделать кнопки белыми и заполнить текущий массив нулями. Уже сохранённые примеры должны оставаться прежними.

## Как рисунок становится данными нейросети

Нейросеть получает числа. Каждая кнопка представляет один пиксель. Читаем пиксели по строкам: слева направо, затем переходим на следующую строку. Получается одномерный массив вида `[0, 0, 1, 1, 0, ...]`.

Если в сетке `R` строк и `C` столбцов, во входном массиве будет `R × C` чисел. Каждый элемент всегда соответствует одной и той же позиции на поле. Размер поля и порядок чтения должны совпадать у всех примеров для одной модели, в том числе при распознавании.

Если нарисована цифра 7, обучающий пример состоит из массива пикселей и отдельного правильного ответа `7`. Ответ не добавляется к входным пикселям: во время обучения с ним сравнивают предсказание сети и корректируют её веса. Позже при распознавании сети дают только массив, а предполагаемую цифру она выдаёт сама. Один рисунок — один пример; для обучения понадобятся разные варианты написания цифр.

Документация: [Avalonia в JetBrains Rider](https://www.jetbrains.com/help/rider/Avalonia.html).

## Сохранение обучающих примеров

Нарисуй цифру, укажи правильный ответ в поле со стрелками и нажми «Сохранить обучающую». Каждое нажатие добавляет одну строку: сначала правильная цифра, затем 15 значений пикселей через пробелы, слева направо и сверху вниз. Чёрный пиксель — 1, белый — 0. Например, для цифры 5:

```text
5 1 1 1 1 0 0 1 1 1 0 0 1 1 1 1
```

`train.txt` создаётся при первом сохранении рядом с исполняемым файлом приложения. При обычном запуске Debug это `bin/Debug/net10.0/train.txt` внутри проекта, при Release — `bin/Release/net10.0/train.txt`. `File.AppendAllText` добавляет новые строки, сохраняя предыдущие. Очистка каталога сборки может удалить этот файл: перед ней скопируй нужные данные в отдельную папку.

`System.IO` входит в .NET, устанавливать дополнительный пакет не нужно. Если поле правильной цифры пустое, запись не выполняется, а фокус возвращается в это поле. После сохранения рисунок остаётся на экране.

## Сохранение тестовых примеров

Кнопка «Сохранить тестовую» добавляет пример в `test.txt` в том же формате: правильная цифра и 15 значений пикселей через пробелы, каждый пример на новой строке. Файл создаётся при первом сохранении рядом с `train.txt`; при обычном запуске Debug путь внутри проекта — `bin/Debug/net10.0/test.txt`. Предыдущие строки сохраняются. Если правильная цифра не указана, запись не выполняется.
